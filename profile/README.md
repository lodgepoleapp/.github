# Contributing

We welcome contributions. Before opening a PR, please:

1. Read the project's `CONTRIBUTING.md` for repo-specific guidelines
2. Open an issue first for non-trivial changes — let's figure it out together
3. Write clear commit messages that explain *why*, not just *what*
4. Keep PRs focused — one concern per pull request

# Code of Conduct

All Lodgepole Appworks projects follow our [Code of Conduct](CODE_OF_CONDUCT.md). We expect respectful, constructive collaboration from everyone who participates.
